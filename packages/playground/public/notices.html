Open-source notices

The playground is part of LVCE devcontainer (MIT).

The prepared environment includes container2wasm v0.8.4 and its Linux, QEMU, BusyBox, runc, tini, and boot firmware dependencies. Their source locations and licenses are listed in the converter’s acknowledgements; exact revisions and build instructions are in its Dockerfile.

Alpine Linux 3.23.3: project, package sources and licenses. Browser terminal transport: xterm-pty (MIT license). Isolation bootstrap: coi-serviceworker (MIT license).

The full startup experiment additionally includes Node.js, Docker Engine, Docker CLI, containerd, and @devcontainers/cli. Alpine package metadata identifies installed package versions; the CLI package and its license files are included in the guest. The repository’s lockfile and full-stack Dockerfile identify the bundled versions.
